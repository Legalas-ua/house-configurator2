# Специфікація нового конфігуратора

Один файл — один елемент. Читаєш тільки те, над чим працюєш зараз.

## Як позначені правила

У кожного правила є **власник**. Це головне, чого бракувало в попередній версії:

| Позначка | Що означає | Чи можна змінити |
|---|---|---|
| 🔒 **ЗАКОН** | Геометрія або фізика. Порушиш — воно просто не працює | Ні. Тут нема про що сперечатись |
| ⚖️ **РІШЕННЯ** | Наш вибір. Поруч завжди написано, скільки коштує інший варіант | Так, будь-коли — це твій виклик |
| ❓ **ВІДКРИТЕ** | Ще не вирішили. Одним рядком, без таблиць «варіант 1 / варіант 2» | — |
| ⚠️ **ГРАБЛІ** | Помилка, яку вже зробили у v2. Опис + чим закінчилось | — |

Якщо десь стоїть 🔒, а ти з ним не згоден — скажи. Можливо, я помилково назвав
законом те, що насправді рішення.

## Елементи

### Ділянка
- `site.md` — земля, межі, орієнтація ❓
- `landscape.md` — газон, доріжки, дерева, паркан ділянки ❓
- `terrace.md` — тераса й паркан тераси ❓

### Планування
- **`room.md`** — кімната-модуль ✅ написано
- `layout.md` — як кімнати складаються в будинок ❓

### Коробка
- `wall.md` — зовнішня стіна, перегородка ❓
- `floor.md` — перекриття, цоколь, фундамент ❓
- `stairs.md` — сходи ❓

### Отвори
- `window.md` — вікно, вітраж ❓
- `door.md` — двері вхідні та міжкімнатні ❓

### Дах
- **`roof.md`** — форма даху ✅ написано
- `roof-trim.md` — кожухи й планки ❓

### Оздоблення
- `material-facade.md` ❓
- `material-roof.md` ❓
- `material-floor.md` ❓

### Продукт
- `flow.md` — кроки, режими редагування, каскадне скидання ❓
- `ui.md` — вигляд, композиція, типографіка, рух ❓
- `price.md` — як рахується ціна, звідки дані ❓

## Порядок

Спершу два зразки — `room.md` (найпростіший) і `roof.md` (найскладніший),
щоб перевірити формат. Далі решта.

## Що вже вирішено по продукту

- Будинок збирається з **кімнат-модулів**; контур, стіни, перекриття й дах
  **виводяться** з набору кімнат.
- **Три режими**: готове · готове з підгонкою · своє з порожнього аркуша.
- Оточення (газон, доріжки, дерева, паркан) потрібне для «живості» моделі.

## Що ще не вирішено

- Для кого сайт: ліди для однієї компанії / готелі / маркетплейс / інструмент
  на продаж забудовникам.
- Дизайн: чи беремо один із двох варіантів у `design/`, чи орієнтуємось на
  конкретний сайт зі списку `design/REFERENCES.md`.
- Набір і порядок кроків.
